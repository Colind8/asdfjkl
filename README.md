# The Alchemist
This is a turn-based adventure game where you brew potions to defeat enemies.

## Setup
Requires Java 25. Entry-point class is `Game.java`.

To play, run `java Game.java`

## How to play
You need to defeat the enemy by brewing a potion. Potions are created with ingredients in your inventory. Each ingredient has a unique effect that can apply to the potion.

When you create a potion, you can throw it at either yourself or your enemies.

The effect of the potion will activate when their turn starts. (for now potions just change HP).

Use check to view you or your enemy's health, description, and applied effects.
